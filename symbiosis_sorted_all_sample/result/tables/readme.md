| Table file | What the table contains | Key columns / column meanings |
|---|---|---|
| `all_central_nif_nod_target_records.tsv` | All central nif/nod target sequences extracted from the GenBank annotation. Each row is one extracted target record. | `gene`: nif/nod gene name; `target_id`: unique extracted target ID; `original_reference`: source reference record; `strand`: gene strand; `target_length`: extracted sequence length. |
| `central_genes_not_found_in_genbank.txt` | Requested central nif/nod genes that were not found in the GenBank annotation. | One gene name per line; used to document missing genes. |
| `central_nif_nod_gene_summary.tsv` | Summary of extracted central nif/nod genes. | `gene`: gene name; `extracted_target_sequences`: number of unique target sequences extracted; `targets_matched_to_original_fasta`: number matched back to FASTA; `exact_locations_in_original_fasta`: number of exact FASTA locations; `status`: match status. |
| `fastp_logs_summary.tsv` | Per-sample trimming QC from fastp JSON files. | `sample`: sample ID; read/base counts before/after trimming; retained reads/bases; Q20/Q30 before/after; GC before/after. |
| `fastp_qc_by_sample_type.tsv` | fastp QC summarized by sample type. | `sample_type`: No/Rh/Ro/MC; `samples`: number of samples; mean read/base retention; mean Q20/Q30 before and after trimming. |
| `fastp_qc_by_sequencing_folder.tsv` | fastp QC summarized by sequencing batch/folder. | `sequencing_folder`: sequencing batch; `samples`: number of samples; mean read/base retention; mean Q20/Q30 before and after trimming. |
| `fastp_qc_overall_summary.tsv` | Overall trimming QC across all 2,907 samples. | `metric`: QC metric name; `value`: dataset-wide value, such as number of samples, mean reads retained, mean bases retained, Q20/Q30 before/after. |
| `nif_nod_coverage_overall_threshold_summary.tsv` | Overall sensitivity of target/sample retention under different coverage thresholds. | Threshold columns such as percent covered and mean depth; sample/target counts passing each threshold. |
| `nif_nod_gene_coverage_summary_by_sample_type_thresholds.tsv` | Gene-level coverage summarized by sample type across filtering thresholds. | `gene`: nif/nod gene; `sample_type`: No/Rh/Ro/MC; threshold columns; number/percent of samples passing coverage and depth filters. |
| `nif_nod_match_summary_by_gene.tsv` | Gene-level summary of how extracted nif/nod targets matched back to original FASTA. | `gene`: gene name; extracted target count; matched target count; exact location count; match status. |
| `nif_nod_matches_in_original_reference.tsv` | Coordinates of each extracted nif/nod target in the original `symbiosis_islands.fasta`. Used for coverage calculation. | `original_reference`: FASTA record name; `bed_start`: 0-based start; `bed_end`: end coordinate; `gene`: gene name; `extracted_target_id`: target ID; `strand`: +/−; `target_length`: target length. |
| `nif_nod_mc_negative_control_mapping_summary.tsv` | Mapping summary for MC-1 and MC-2 negative/mock controls against nif/nod targets. | `sample`: MC sample; `total_reads`; `mapped_reads`; `mapped_percent`; `properly_paired`; `properly_paired_percent`; `top_target`; `top_target_mapped_reads`. |
| `nif_nod_region_coverage_all_samples.tsv.gz` | Full compressed coverage table for every sample-target combination. This is the main coverage output. | `sample`; `sequencing_folder`; `site`; `sample_type`; `is_mc_control`; `gene`; `original_reference`; `bed_start`; `bed_end`; `target_id`; `strand`; `target_length`; `covered_bases`; `percent_covered`; `mean_depth`; `max_depth`. |
| `nif_nod_target_mc_aware_ranking_thresholds.tsv` | Target-ranking table using biological-sample signal and MC-control background. | `target_id`; `gene`; `classification`; good sample counts/percents by sample type; MC good counts; depth/coverage summaries; ranking metrics. |
| `nif_nod_targets_without_exact_match.tsv` | Extracted targets that did not match exactly back to the original FASTA. | `target_id`; `gene`; sequence/target information; reason or status showing no exact match. |
| `symbiosis_islands_85_reference_names_lengths.tsv` | Names and lengths of the 85 FASTA records in `symbiosis_islands.fasta`. | Column 1: FASTA record name; column 2: sequence length in bp. |
| `symbiosis_islands_exact_duplicate_records.tsv` | Exact duplicate records found in the 85-reference FASTA. | `duplicate_group`: duplicate group ID; `record_name`: FASTA record name; `length`: sequence length. |
| `symbiosis_mapping_by_sample_type.tsv` | Mapping QC summarized by sample type after mapping reads to `symbiosis_islands.fasta`. | `sample_type`: No/Rh/Ro/MC; sample count; mapped-read percent; properly paired percent; other flagstat-derived metrics. |
| `symbiosis_mapping_by_sequencing_folder.tsv` | Mapping QC summarized by sequencing batch/folder. | `sequencing_folder`: batch name; sample count; mapped-read percent; properly paired percent; other mapping metrics. |
| `symbiosis_mapping_completion_summary.txt` | Text summary confirming mapping completion. | Counts of expected samples, completed BAM files, BAM indexes, and flagstat reports. |
| `symbiosis_mapping_flagstat_summary.tsv` | Per-sample mapping QC from `samtools flagstat`. | `sample`; total reads; mapped reads; mapped percent; paired reads; properly paired reads; properly paired percent; singletons; mate mapped to different reference. |
| `symbiosis_mapping_overall_summary.tsv` | Overall mapping QC across all 2,907 samples. | `metric`: mapping metric; `value`: dataset-wide value, such as mean/median mapped percent and properly paired percent. |
| `v2_nifH_target_filtering_strategy_comparison.tsv` | Comparison of nifH target-selection strategies. | `target_id`; `ref`; `classification`; good sample counts/percents for No/Rh/Ro/MC; biological total; strategy-specific keep/exclude decisions. |
| `v2_nifH_target_filtering_strategy_comparison_biological_plus_one_MC.tsv` | Alternative nifH target-selection strategy allowing limited MC signal. | Same style as the main strategy table, but classification allows one MC-positive case as a sensitivity analysis. |
| `v2_nifH_target_good_coverage_by_sample_type_pct80_depth10.tsv` | Counts of good-coverage samples for each nifH target using percent covered ≥80% and mean depth ≥10x. | `target_id`; `ref`; `classification`; `No_good_samples`; `No_total_samples`; `No_good_percent`; same columns for Rh, Ro, and MC. |
| `v2_top_mc_aware_targets_pct80_depth10.tsv` | Final top target list after MC-aware filtering at percent covered ≥80% and mean depth ≥10x. | `target_id`; `gene`; `ref`; classification/ranking fields; biological good-sample counts; MC-control counts; selected/not selected status. |
